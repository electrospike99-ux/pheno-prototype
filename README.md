# Pheno prototype (iPhone app build)

The onboarding prototype from Claude, packaged so it can be added to an iPhone Home Screen and open full screen like an app.

Open the GitHub Pages address in Safari on the iPhone, tap Share, then "Add to Home Screen".
On a computer the same address shows the full prototype page with its controls.

Updated by Claude on request ("sync the iPhone app"). Review statuses don't save here; reviewing stays on the claude.ai prototype.
